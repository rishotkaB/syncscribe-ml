# Пример для проверки diff (этап 3)

Две версии одного руководства. Что изменилось между `admin_guide_v1.md` и `admin_guide_v2.md`:

1. Требования: 8 vCPU / 32 ГБ → 16 vCPU / 64 ГБ (изменение внутри абзаца, остальные предложения те же).
2. Таблица: PostgreSQL 14 → 16.
3. Установка: добавлен шаг «Укажите токен доступа в agent.conf», старый шаг 3 стал шагом 4.
4. Вставлен раздел «3. Настройка SSO», «Настройка интеграций» сдвинулась с 3 на 4.
5. Confluence: 15 → 5 минут (Jira в том же абзаце не менялась).
6. Раздел «4. Экспорт» удалён целиком.

Не изменилось: раздел «Резервное копирование», ОС, Qdrant.
Ожидания зашиты в `tests/test_diff.py`.

`user_guide.md` — производный документ, написанный по v1. Его проверяет `scripts/check_docs.py`.
Ожидается, что затронуты 5 абзацев из 7: железо (8 ядер), установка (нет шага с токеном),
ссылка на раздел 3, Confluence 15 минут, выгрузка в Word. Jira и резервные копии не затронуты.
