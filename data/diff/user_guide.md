# Быстрый старт SyncScribe

Для пилота подготовьте виртуальную машину с 8 ядрами, 32 ГБ оперативной памяти и диском SSD на 200 ГБ.

Для установки скачайте дистрибутив, распакуйте его в /opt/syncscribe и запустите сервис командой `syncscribe start`.

Подключение Confluence и Jira описано в разделе 3 «Настройка интеграций».

Изменения в Confluence попадают в SyncScribe не позже чем через 15 минут.

Задачи из Jira подтягиваются раз в час.

Готовый документ можно выгрузить в Word.

Если что-то пошло не так, данные можно восстановить из ночной копии за последние две недели.
