# Большой пример для замера скорости

Сгенерирован `python scripts/make_large_example.py`, руками не правится.

- `source_v1.md`, `source_v2.md` — источник: 15 разделов по 4 параметра. В v2 изменено 13 параметров в 9 разделах и добавлено одно предложение (2FA), которое ничего в документе не делает ложным.
- `derived.md` — производный документ: 3 главы с разными формулировками, 198 абзацев.
- `labels.json` — разметка: для каждого абзаца с фактом `impacted` и ожидаемая правка. Затронуто 39 абзацев (13 × 3).

Формулировки шаблонные, для оценки качества пример лёгкий. Он нужен, чтобы честно замерить время на документе реального размера и сравнить обычный режим с `--fast`.

## Режим «источник истины» (`truth/`)

- `admin_guide.md` — источник истины (это `source_v2.md`), `faq.md` — второй источник. В FAQ два параметра расходятся с руководством (время жизни сессии, число одновременных сессий), один совпадает (размер файла).
- `derived.md` — тот же документ плюс глава «Поддержка» из 6 абзацев, о которых источники молчат (их трогать нельзя).
- `labels.json` — ожидаемый вердикт: `contradicts` (36 абзацев), `sources_conflict` (6), `ok` (остальные).
