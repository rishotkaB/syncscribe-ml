# Руководство по эксплуатации SyncScribe

## Настройка

Этот раздел предназначен для администраторов и инженеров внедрения.

Параметр «срок хранения журналов аудита» по умолчанию равен: 90 дней.

Параметр «срок хранения черновиков» по умолчанию равен: 30 дней.

Параметр «срок хранения резервных копий» по умолчанию равен: 14 дней.

Параметр «срок хранения удалённых проектов в корзине» по умолчанию равен: 30 дней.

Параметр «максимальный размер файла» по умолчанию равен: 50 МБ.

Параметр «максимальная длина документа» по умолчанию равен: 300 страниц.

Параметр «число файлов в одной загрузке» по умолчанию равен: 20 файлов.

Параметр «поддерживаемый формат таблиц» по умолчанию равен: XLSX.

Параметр «число попыток входа до блокировки» по умолчанию равен: 5 попыток.

Параметр «время блокировки учётной записи» по умолчанию равен: 15 минут.

Перед изменением настроек согласуйте их с владельцем системы.

Параметр «минимальная длина пароля» по умолчанию равен: 8 символов.

Параметр «срок действия пароля» по умолчанию равен: 90 дней.

Параметр «время жизни сессии» по умолчанию равен: 24 часа.

Параметр «время бездействия до выхода» по умолчанию равен: 30 минут.

Параметр «число одновременных сессий» по умолчанию равен: 3 сессии.

Параметр «срок действия ссылки сброса пароля» по умолчанию равен: 24 часа.

Параметр «интервал опроса Confluence» по умолчанию равен: 15 минут.

Параметр «интервал опроса Jira» по умолчанию равен: 60 минут.

Параметр «интервал опроса GitLab» по умолчанию равен: 30 минут.

Параметр «число повторов при ошибке синхронизации» по умолчанию равен: 3 повтора.

Все изменения настроек фиксируются в журнале аудита.

Параметр «число ядер процессора» по умолчанию равен: 8 ядер.

Параметр «объём оперативной памяти» по умолчанию равен: 32 ГБ.

Параметр «объём диска» по умолчанию равен: 200 ГБ.

Параметр «версия PostgreSQL» по умолчанию равен: PostgreSQL 14.

Параметр «канал уведомлений об ошибках» по умолчанию равен: email администратора.

Параметр «порог уверенности для уведомления автора» по умолчанию равен: 0,7.

Параметр «частота дайджеста изменений» по умолчанию равен: раз в неделю.

Параметр «язык уведомлений по умолчанию» по умолчанию равен: русский.

Параметр «число коннекторов в стандартной лицензии» по умолчанию равен: 3 коннектора.

Параметр «число пользователей в стандартной лицензии» по умолчанию равен: 50 пользователей.

Если параметр не указан явно, используется значение по умолчанию.

Параметр «срок пробного периода» по умолчанию равен: 14 дней.

Параметр «стоимость дополнительного коннектора» по умолчанию равен: 20 000 рублей в год.

Параметр «формат экспорта по умолчанию» по умолчанию равен: DOCX.

Параметр «максимальный размер выгрузки» по умолчанию равен: 200 МБ.

Параметр «срок хранения ссылки на выгрузку» по умолчанию равен: 7 дней.

Параметр «число выгрузок в сутки» по умолчанию равен: 100 выгрузок.

Параметр «лимит запросов к API» по умолчанию равен: 100 запросов в минуту.

Параметр «время ответа API (p95)» по умолчанию равен: 500 мс.

Параметр «срок действия API-токена» по умолчанию равен: 1 год.

Параметр «версия API по умолчанию» по умолчанию равен: v1.

Настройки применяются после перезапуска сервиса.

Параметр «число результатов на странице» по умолчанию равен: 20 результатов.

Параметр «языки полнотекстового поиска» по умолчанию равен: русский и английский.

Параметр «задержка индексации нового документа» по умолчанию равен: 5 минут.

Параметр «максимальная длина запроса» по умолчанию равен: 256 символов.

Параметр «интервал сбора метрик» по умолчанию равен: 60 секунд.

Параметр «срок хранения метрик» по умолчанию равен: 30 дней.

Параметр «порог загрузки CPU для оповещения» по умолчанию равен: 80%.

Параметр «порог свободного места на диске для оповещения» по умолчанию равен: 10%.

Параметр «время запуска ночной копии» по умолчанию равен: 03:00.

Параметр «число хранимых копий» по умолчанию равен: 14 копий.

Рекомендуем проверять настройки после каждого обновления.

Параметр «время восстановления из копии» по умолчанию равен: 2 часа.

Параметр «место хранения копий» по умолчанию равен: S3-хранилище заказчика.

Параметр «число ревьюеров для публикации» по умолчанию равен: 1 ревьюер.

Параметр «срок рассмотрения правки» по умолчанию равен: 5 рабочих дней.

Параметр «максимальное число правок в пакете» по умолчанию равен: 100 правок.

Параметр «срок хранения отклонённых правок» по умолчанию равен: 1 год.

Параметр «размер контекста модели» по умолчанию равен: 32 000 токенов.

Параметр «таймаут вызова модели» по умолчанию равен: 60 секунд.

Параметр «число повторов при сбое модели» по умолчанию равен: 3 повтора.

Параметр «температура генерации» по умолчанию равен: 0,1.
